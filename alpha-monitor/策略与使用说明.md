# v2：小时观察、持仓退出和证据边界

这是一套研究提醒规则，不是已证实的百倍币预测模型。云端不连接交易账户，不自动下单。当前新策略只覆盖 BSC；原来的多链/日线命令保留。

## 历史研究究竟转化了哪些规则

|历史研究支持的观察或限制|落地方式|证据强度|
|---|---|---|
|Alpha 与合约先后顺序不同，等双条件可能错过早期上涨|分开显示仅 Alpha 与 Alpha＋USDT永续池|上线顺序是观察事实，不代表哪个池收益更高|
|放量、突破、回踩值得进一步检验|保留日线规则；新增小时异动→突破→后续回踩状态跟踪|小时阈值是新假设，未用历史数据证明盈利|
|同一项目的涨幅高度依赖入场时间|记录实际触发时间与当时可获取报价，禁止回填历史最低价|前瞻记录，不是成交回测|
|暴涨与极深回撤可以共存|登记真实成本后提醒止损、分批止盈、峰值回撤|退出参数为默认配置，不是历史最优参数|
|100倍需考察估值与供应|市值/FDV、流通比例、100倍静态市值过滤|当前估值检查，不能倒推历史估值|
|当前名录有幸存者偏差，赢家案例不能证明预测优势|同时保存无信号与阻断信息，保留失败/过期数据|历史研究仍不等于完整历史样本|
|缺少历史筹码/关联钱包/解锁档案|显式标未知；补充当前第三方快照与带来源人工披露|不能宣称是历史暴涨的共同原因|

可复现历史报告在 `data/研究报告.md`：180个项目中134个使用Alpha现货价格，46个使用明确标记的合约代理。两组不混用来计算现货前置信号统计。个案数字均受报告起点、观察窗口及上市日期字段限制。

## 新增提醒

### 提前观察

采用最近25根连续、已收盘小时K线（24小时基准＋当前小时），没有足够历史或出现缺口则不触发。

共同门槛：流通市值大于0且≤1亿美元；市值与FDV基本一致、流通比例≥10%；报告流动性≥10万美元；24h成交额≥10万USDT；24h报告涨幅≤60%。双上市池还沿用原来的合约报价、成交和资金费率过滤。

最新完整小时成交额≥1万USDT、24h涨幅0–60%、小时涨幅0–20%，再检查：

- **提前观察**：小时成交额≥前24小时中位数2倍，收盘接近前24小时高点（95%–100%）。同一地址至少间隔6小时再发这一类提醒。
- **突破参考**：量比≥2.5，小时收盘突破前24小时高点，但不超出8%；当前新鲜报价在突破价之上且不超过信号收盘价3%。
- **回踩参考**：必须先实时观察到一次突破，随后12小时内，另一根已收盘小时K线回踩支撑附近并收回，当前报价不明显追高。不从历史K线回填一个“早就知道”的突破。
- **失效提醒**：观察建立后的24小时内，后续小时收盘跌破支撑3%、新鲜报价跌破支撑5%，或新出现明确门槛阻断。它不是你的实际卖出成交记录。

这些数值是待验证的人工阈值。缺失的链上安全、解锁、机构归属仍会在消息中显示。信号名称中的“入场参考”不等于可以买。

每轮默认检查24个符合基础门槛的项目，大部分名额按最久未检查轮换，小部分给近期活跃项目；尚未失效的突破项目另有最多24个检查名额。不是每轮为310个项目都请求全部小时数据。扫描结束后等待300秒；实际检测延迟还受轮换、网络和限流影响。报价过期时不拿旧价触发买卖条件。

### Telegram 登记实际持仓

在与你已配置的机器人私聊中发送：

```text
/help
/status
/positions
/buy 完整BSC合约地址 实际买入均价
/buy 完整BSC合约地址 实际买入均价 15 20
/close 持仓编号
```

`/buy` **只是记录你已经买入的现货成本**，不会买入。均价单位为 USDT/枚，不要填写总投入额。15和20分别为止损百分比、移动回撤百分比，可在1–80之间修改。最多登记20个实际持仓；相同地址不重复建仓。加减仓后均价改变时，先关闭旧记录再重建，新记录重新积累峰值。

默认退出参考：成本下跌15%；浮盈达到30%后，价格从登记后采样峰值回撤20%；达到成本1.5倍、2倍、3倍时各提醒一次分批止盈。报告流动性低于10万美元或较登记时下降50%，以及第三方明确安全风险/已录入的大额近期解锁，也会提示。

峰值仅是登记后的采样最高报价，不是市场真实最高价；瞬时穿越阈值又恢复可能漏报。消息送达不代表能按提示价成交。每个持仓每个止盈/止损阈值只发一次；仓位不会自动关闭，卖出后请 `/close 编号`。

没有新鲜报价时发送单独的数据缺失提醒，不假造卖出价。仅支持成本跟踪，不计算杠杆、合约单位、强平或真实持仓数量。

命令只接受配置的**私聊会话且发送者就是该会话用户**。群消息、其他用户、转发消息和超过10分钟的旧命令不执行。处理命令、保存偏移量和入队回复在同一数据库事务中完成；重启不会重复登记。

### 前瞻纸面观察

突破/回踩信号按当时实际获取的报价开始观察，最多同时20条；记录后续采样价、峰谷以及24/72/168小时观察值。固定时点允许最多30分钟延迟，错过就标缺失，不用后来的报价回填。无费用、滑点、真实成交或完整退出模拟，不展示“策略胜率”。这些记录为以后的独立验证积累数据，尚不能证明策略有效。

## 持仓集中、关联钱包、解锁与机构

- **GoPlus 当前快照**：在可能发出新信号及登记持仓时检查，成功快照缓存1小时，缺失结果缓存10分钟。蜜罐、增发、转账暂停、黑名单、修改余额、隐藏所有者、修改税率、税率超过10%等已返回风险会阻断新的入场参考，并对登记持仓提示。供应商检测不等于我们完成了卖出模拟；未知不等于安全。
- **集中度**：记录供应商前十条持仓的原始占比；若数据不完整则未知。没有可靠剔除池、桥、托管和交易所前，不将其解释为控盘比例，不给买入加分。
- **关联钱包**：暂未接入完整转账图谱或资金来源分析，明确标为未知，不把同步交易直接归于同一主体。
- **解锁**：暂未自动接入全量可信日历。可以在服务器的 `/var/lib/alpha-radar/risk-overrides.json` 按地址录入带来源的披露；7天内核验过的记录才使用，未来7天解锁≥当前流通量5%时阻断新信号并提示持仓风险。
- **机构**：可记录公开投资方、做市商、金库、托管方、交易所、钱包标签或有来源的指控。记录是“带来源但未独立核验的归属说法”，不等于操盘证明；机构名称不贡献买入分。供应商的地址标签也仅是辅助线索。

人工披露格式如下（示意占位值，请替换真实地址、来源及Unix秒时间；没有证据不要填写）：

```json
{
  "0x完整BSC地址": {
    "reviewed_at": 0,
    "unlock_at": 0,
    "fraction_of_circulating": 0.06,
    "source": "https://项目官方披露网址",
    "entities": [
      {
        "name": "公开披露的机构名称",
        "role": "investor",
        "wallets": [],
        "source": "https://公开证据网址",
        "reviewed_at": 0
      }
    ]
  }
}
```

`fraction_of_circulating=0.06` 表示6%，不是6。机构记录超过30天需重新核验。录入并不自动验证网址内容或证明控制关系。本次没有凭空填入任何机构或解锁记录。
