## 零、本轮修复(你发现的 cashtag 问题)

### cashtag 三个 bug(已修)

| Bug | 实例 | 影响 |
|---|---|---|
| 大小写不统一 | `okt` → `$okt` | 币安标准是大写 `$OKT`, 小写**可能不解析不链接** |
| 清洗造出假符号 | `A-1` → `$A1`、`A B` → `$AB` | **指向不存在的币**, 误导读者且无法归因 |
| 漏掉合法符号 | `1INCH` 不加 cashtag | 1INCH 是真实币安代币, 白白漏掉 |

**修复后**: 统一大写; 含空格/连字符等一律**跳过**(不清洗); 允许数字开头; 长度限 15。

## 一、你问的三个问题 — 都已落实

### 1. meme S 级阈值: 集中度 16~18% 靠聪明钱入选, 这个取舍对吗?

**查完发现: 真正的问题不在集中度, 而在"砸盘风险"没被考虑。**

原阈值只看"聪明钱+流动性+集中度≤80%", 漏掉了:
- `holdersSniperPercent`(**狙击机器人占比**) — 高则开盘就被砸
- `holdersDevPercent`(**dev 持仓占比**) — 高则随时可砸

**已加风险过滤**: 狙击手 ≥50% 或 dev ≥20% → 直接降级（不管聪明钱多少）。

**结果**: ZKINU / okt / 鲲鹏 **确实从 S 降级了**（它们集中度虽低, 但砸盘风险高）。现在 S 级 = 1 个（狴犴寶貝, 集中度40%, 聪明钱81人）。

**结论**: 集中度低本身**不是**问题（对 meme 币来说分散反而降低砸盘风险），但你原来的直觉是对的——那三个币确实不该是 S 级，只是原因不是集中度，而是砸盘风险。

### 2. 聪明钱榜排序: 改成"人数 × 涨幅"吗?

**崩盘币（跌幅 >10%）完全不显示**（原来是显示为"可关注", 是错的, 已修）。
